# DOBI Landing Page

Una landing page moderna y minimalista para DOBI, un agente de IA en blockchain que valida y gestiona activos reales (RWAs).

## 🚀 Características

- **Diseño Moderno**: Interfaz futurista con animaciones fluidas
- **Completamente Responsivo**: Optimizado para desktop y mobile
- **Animaciones Avanzadas**: Implementado con Framer Motion
- **Rendimiento Optimizado**: Construido con Next.js 14 y TailwindCSS
- **TypeScript**: Tipado completo para mejor mantenibilidad

## 🛠️ Tecnologías Utilizadas

- **Next.js 14** - Framework de React
- **TailwindCSS** - Utility-first CSS framework
- **Framer Motion** - Librería de animaciones
- **TypeScript** - Superset tipado de JavaScript
- **Lucide React** - Iconos modernos

## 📦 Instalación

1. Clona el repositorio:
\`\`\`bash
git clone [repository-url]
cd dobi-landing
\`\`\`

2. Instala las dependencias:
\`\`\`bash
npm install
\`\`\`

3. Ejecuta el servidor de desarrollo:
\`\`\`bash
npm run dev
\`\`\`

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 🎯 Secciones de la Landing

1. **Hero Section**: Introducción impactante con CTAs principales
2. **Value Proposition**: 3 columnas destacando los beneficios clave

6. **Dashboard Demo**: Mockup interactivo del dashboard
7. **Tokenomics**: Información del token y staking

## 🔧 Personalización

Para personalizar la landing:

1. **Colores**: Edita `tailwind.config.js`
2. **Animaciones**: Modifica los componentes con Framer Motion
3. **Contenido**: Actualiza el texto en cada componente
4. **Enlaces**: Cambia las URLs en los botones CTA
